# Decision records

Short notes (ADRs) for decisions where there was a real choice with a trade-off.
Routine fixes and edits do not belong here: they go in the commit message and `CHANGELOG.md`.

Write one when you could reasonably have done it another way and future-you would ask "why?".

Name files `NNNN-short-title.md` and keep each to about one page:

```markdown
# NNNN. Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem or situation forced a choice?

## Options considered
1. Option A - pros / cons
2. Option B - pros / cons

## Decision
What we chose, and why.

## Consequences
What gets easier, what gets harder, what to watch for.
```
